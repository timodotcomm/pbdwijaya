# PBD Wijaya Redesign — Multi-page Static Prototype

Prototype ini terdiri dari halaman Indonesia dan English, menggunakan konten publik pbdwijaya.co.id yang telah dirapikan penulisannya.

## Halaman Indonesia
- index.html
- profil.html
- produk.html
- layanan.html
- klien.html
- proyek.html
- kontak.html
- lowongan.html

## English
Folder `en/` berisi Home, Profile, Product, Services, Clients, Projects, dan Contact.

## Catatan aset
Logo klien dan tiga lembar daftar klien menggunakan URL aset publik asli dari pbdwijaya.co.id. Dokumen sertifikasi/legalitas juga ditautkan ke file sumber. Ilustrasi pada hero dan kartu proyek adalah elemen visual redesign, bukan pengganti permanen foto proyek. `asset-manifest.json` mencatat aset yang digunakan.

Buka `index.html` di browser atau jalankan local server: `python -m http.server 8000`.
